# Coffee Machine Task for week 9

In this task, you will create a simple coffee machine simulation using object-oriented programming principles.
The coffee machine is made of two component:
 CoffeeMaker and MilkDispenser. The CoffeeMaker is responsible for brewing coffee, while the MilkDispenser is responsible for dispensing milk.

CoffeeMaker class should have the following methods:
- `brewCoffee()`: This method should print "Brewing coffee..." to the console.

MilkDispenser class should have the following methods:
- `dispenseMilk()`: This method should print "Dispensing milk..." to the console

CoffeeMachine class should have the following methods:
- `makeCoffee()`: This method should call the `brewCoffee()` method of the CoffeeMaker class and the `dispenseMilk()` method of the MilkDispenser class.

Utlize the CoffeeMachine class in a main class 'TestCoffeeMachine' to simulate making a cup of coffee with milk.
