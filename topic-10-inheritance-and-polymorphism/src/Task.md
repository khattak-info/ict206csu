# Inheritance and Polymorphism Task

Create a car class which has three subclasses
- PetrolCar
- DieselCar
- ElectricCar

they have a method which returns the milage of the car. The mileage for each type of car is as follows:
- PetrolCar: 15 km/l
- DieselCar: 20 km/l
- ElectricCar: 100 km/kWh

These methods should be overridden in each subclass to return the appropriate mileage. The input the method is the amount of fuel in litres or kWh and the output is the distance that can be travelled with that amount of fuel.
